# 🎛️ مرکز کنترل PythonTraderBot (Streamlit)

اینترفیس کامل برای کنترل اجرای ربات‌های معاملاتی و بک‌تست‌های ریپازیتوری PythonTraderBot.

## اجرا

```bash
pip install -r ../requirements.txt
streamlit run app.py
```

مرورگر: `http://localhost:8501`

## صفحات

| صفحه | توضیح |
|---|---|
| 🏠 داشبورد | نمای کلی + آمارهای اعلام‌شدهٔ نویسنده |
| 🤖 ربات‌های زنده | اجرا/توقف/لاگ زندهٔ ۱۴ ربات (MT5 روی ویندوز؛ ربات اخبار همه‌جا) |
| 📈 بک‌تست | ۶ بک‌تست: مارکوف، لوریج SPY→UPRO، اسکالپر HA_RSI، بهینه‌ساز SMA، مایکل هریس (MT5)، SP2L پیشرفته (MT5) |
| 📊 آمار و وین‌ریت‌ها | جدول وین‌ریت/سودهای ادعاشده با توضیح کامل |
| 🧰 ابزارها | دریافت کندل از MT5 + ساخت سطوح حمایت/مقاومت + وضعیت پیکربندی |
| ⬇️ دانلود پکیج | ساخت و دانلود ZIP کامل مجموعه |
| 📖 راهنما | راه‌اندازی، مدیریت ربات‌ها، نکات ریسک |

## فایل‌ها

- `app.py` — اپلیکیشن اصلی (اجرای این فایل)
- `engines.py` — موتورهای بک‌تست (پورت‌شده از نوت‌بوک‌ها)
- `catalog.py` — کاتالوگ ربات‌ها + آمارهای ادعاشده
- `runner.py` — مدیریت subprocess ربات‌های لایو + لاگ
- `sr_tools.py` — تشخیص و خوشه‌بندی سطوح حمایت/مقاومت
- `mt5_utils.py` — ابزار اتصال متاتریدر (با محافظ)
- `build_toolkit.py` — ساخت ZIP پکیج دانلودی
